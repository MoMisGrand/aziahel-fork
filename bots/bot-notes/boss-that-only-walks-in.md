Fixed: Bots waited by a dungeon boss that only joins a fight started beside it
Some dungeon bosses, like Pops O'Leary in The Ironworks, never start a fight when you walk into them. They only walk into a fight you start with the creature next to them. Bots stood on him or waited by him for over half an hour. Inside dungeons they now start the fight with the creature beside such a boss, so the boss walks in.
Where: Marleybone, The Ironworks, and any dungeon boss that works this way.
Test: Send a bot on "Internal Investigation" and watch it fight the O'Leary Napper next to Pops O'Leary, with Pops joining.
