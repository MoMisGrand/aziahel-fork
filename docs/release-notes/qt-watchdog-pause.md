New: The Quest Team pauses itself after two hours with nothing done
Like Ultimus, if the team goes two hours without finishing a step, gaining a level or reaching a new area, it pauses itself instead of going round in circles all night. It writes what it was doing to watchdog-stop.txt in the Quest Team logs folder. Press Resume on the Quest Team page in Ahziael to start it again.
Where: The Quest Team page in Ahziael, using the same watchdog time as Ultimus.
Test: Nothing to set up. If it ever happens, the team shows as paused and its log has a "WATCHDOG STOP" line.
