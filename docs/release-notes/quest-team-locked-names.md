Changed: The Quest Team has fixed names and genders
The four Quest Team wizards always have the same names now: Freya (Ice, female), Terra (Life, female), Anubis (Death, male) and Chaac (Storm, male). The wizards you have now are renamed when the server starts, and a wizard of the wrong gender gets new looks for the right one. A Restart makes the new wizards with these names too, and they can't be changed in settings.
Where: In the game, the Quest Team's name plates, and Ahziael's Quest Team page.
Test: Start the server with the Quest Team on. Their name plates read Freya, Terra, Anubis and Chaac, with the right genders.
