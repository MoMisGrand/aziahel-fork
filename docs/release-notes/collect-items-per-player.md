Fixed: Picking up a quest item like a gemstone took it away from everyone else
When one wizard picked up an item for a "collect" step, such as the gemstones in the Hall of Champions for Get Some Bling, it vanished for every other wizard in the area too. It only came back once the whole area was empty, so in a busy area nobody else could finish the step. Now the item disappears only for the wizard who picked it up, and everyone else on the same step can still collect it, just like the live game.
Where: Every quest step where you collect several items, such as the Hall of Champions gemstones in Krokotopia.
Test: With two wizards on Get Some Bling, have the first pick up a gemstone. The second should still see the same gemstone and be able to pick it up.
