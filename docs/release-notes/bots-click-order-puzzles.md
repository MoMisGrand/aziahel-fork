New: Ultimus and the Quest Team solve click-order puzzles
When a quest's people talk about using things in the right order, Ultimus and the Quest Team use them in the order the quest's words point to. If nothing happens after using all of them, they try another order, the way a player would. Once an order works it is written down, so next time it is done right away. This also covers puzzles that bring out a boss, like the Sand Thumpers in Cavern of the Wurm.
Where: Ultimus and Quest Team, no setting. Orders that worked are kept in bot-puzzles.json in the ID lookup folder.
Test: Let Ultimus reach Cavern of the Wurm in Marleybone. His log shows him using the Sand Thumpers, trying another order if needed, then fighting the Great Wurm.
