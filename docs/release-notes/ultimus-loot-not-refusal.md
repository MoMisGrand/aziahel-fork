Fixed: Loot and pity messages no longer read as a server refusal
When Ultimus or the Quest Team got stuck, the check that looks for the cause read a drop message such as "a drop that is not junk" as the server refusing something, and asked for a server fix. Drop, pity, loot and experience messages are now only noted, never counted as a refusal.
Where: The stuck reports on the Ultimus and Quest Team issue pages.
Test: Win a fight with Ultimus so a drop message shows, let him get stuck, and check that his report no longer blames the server for it.
