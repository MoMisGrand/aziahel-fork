Fixed: Tree of Life step in Left Behind
Walking up to the dead Tree of Life in MooShu now finishes the "Go to Tree of Life" step of Left Behind. The game files give the circle round the tree a copy number on its name, so the server never matched it and the step could not be done by anyone. Any quest step with the same kind of copied name now finishes too.
Where: MooShu, Tree of Life dungeon (Left Behind).
Test: Start Left Behind, talk to Hideo Kebo, then walk up to the tree; the step should tick off.
