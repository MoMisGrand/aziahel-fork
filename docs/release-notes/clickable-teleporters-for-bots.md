Fixed: Bots use clickable teleporters like the Crystal Vortex
Some things you click to be teleported, like the Crystal Vortex in the Tower Archives, were not known to the bots as a way anywhere, so they never used them. Every such teleporter whose landing the server knows now counts as a door, so the bots press it the way a player does. It also shows as a door on the minimap.
Where: Dragonspyre, The Tower Archives, and other clickable teleporters.
